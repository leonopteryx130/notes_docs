# DQN（Deep Q-Network）

### Q-learning 的问题

表格型 Q-learning 要为每一个 $$(s, a)$$ 单独存一个 Q 值。多数实际任务里，状态或动作空间很大（例如原始像素、连续状态），Q 表会爆炸，既存不下也学不完。

思路是：不再维护整张表，而是用带参数 $$\theta$$ 的函数 $$Q(s, a; \theta)$$（通常是神经网络）去**近似**动作价值。参数共享后，相似状态可以泛化，规模问题就变成「把 Q 学得够准」。这就是 DQN（Deep Q-Network）要做的事。

### 基本思路

DQN 把 Q-learning 的表格更新改成「用神经网络拟合 Q」，训练方式很像监督学习：给网络一个输入 $$(s, a)$$，让它输出的 $$Q(s, a; \theta)$$ 去逼近一个标签。区别在于：**这个标签不是事先标好的，而是用环境即时奖励 + 对未来价值的估计临时拼出来的**（TD 目标）。

若标签也完全由正在更新的同一套参数 $$\theta$$ 算出，标签会跟着网络一起晃，训练容易发散。DQN 因此拆成两套参数：

- **当前网络 $$Q(s, a; \theta)$$**：正在训练的网络，负责选动作，也负责被梯度更新。
- **目标网络 $$Q(s, a; \theta^-)$$**：参数 $$\theta^-$$ 定期从 $$\theta$$ 拷贝过来，在两次拷贝之间保持冻结；只用它算 TD 目标里的「未来价值」，当作暂时固定的参照。

于是：

1. 与环境交互得到转移 $$(s, a, r, s')$$；
2. 用目标网络构造标签（TD 目标）：$$y = r + \gamma \max_{a'} Q(s', a'; \theta^-)$$（若 $$s'$$ 为终止态，则 $$y = r$$）；
3. 用 loss 推动当前网络：让 $$Q(s, a; \theta)$$ 靠近 $$y$$；
4. 每隔若干步把 $$\theta$$ 同步到 $$\theta^-$$，让参照系跟上最新学到的 Q，又不至于每步都变。

### 网络结构详解

DQN 智能体内部有**两个结构相同的 DNN**，参数各自独立：

| 网络 | 参数 | 是否参与训练 | 作用 |
|------|------|--------------|------|
| **当前网络** | $$\theta$$ | **是** | 选动作；输出 $$Q(s, a; \theta)$$ 参与 loss，接收梯度更新 |
| **目标网络** | $$\theta^-$$ | **否** | 仅用于计算 TD 目标中的 $$\max_{a'} Q(s', a'; \theta^-)$$，参数在两次同步之间保持冻结 |

二者分工可以概括为：**当前网络负责「学」和「做决策」，目标网络负责「估未来、当标签」**。目标网络不参与反向传播，避免标签随当前网络每步一起变化，导致「自己追自己」、训练发散。

每隔若干步（或每回合结束），将当前网络的参数拷贝到目标网络：$$\theta^- \leftarrow \theta$$。这样估未来的参照会跟上最新学到的 Q，又不会在每一步都跟着变。

上图是 DQN 智能体与环境交互的整体结构：

- **状态 $$s$$** 作为输入进入**当前网络**（参数 $$\theta$$），输出各动作的 Q 值，智能体据此**执行动作 $$a$$**。
- **环境**收到动作后返回**即时奖励 $$r$$** 和新的观测；智能体进入下一状态 $$s'$$，循环继续。
- 训练时，把 $$s'$$ 输入**目标网络**（参数 $$\theta^-$$），得到对未来价值的估计；与即时奖励 $$r$$ 一起构成 TD 目标，通过 loss **回传梯度，只更新当前网络的 $$\theta$$**。

与表格型 Q-learning 的 Q 表对应，这里的 DNN 就是「可泛化的 Q 函数近似器」；DQN 再复制一份结构相同、参数为 $$\theta^-$$ 的目标网络，形成上述双网络结构。


### 训练过程

单步训练可以拆成「与环境交互」和「更新网络」两部分。下面按时间顺序说明（与上文符号一致）。

**1. 选动作并执行**

- 把当前状态 $$s$$ 输入**当前网络**，得到该状态下每个动作的 Q 值：$$Q(s, a_1; \theta), Q(s, a_2; \theta), \ldots$$
- 按策略选动作 $$a$$（训练时常用 **ε-贪心**：以概率 $$\varepsilon$$ 随机探索，否则选 Q 最大的动作）。
- 在环境中执行 $$a$$，得到即时奖励 $$r$$ 和下一状态 $$s'$$。

**2. 构造 TD 目标**

- 把 $$s'$$ 输入**目标网络**，得到下一状态各动作的 Q 值，取最大者作为「从这里继续走，未来大概能有多好」的估计：

$$\max_{a'} Q(s', a'; \theta^-)$$

- 与即时奖励合成 TD 目标（非终止态）：

$$y = r + \gamma \max_{a'} Q(s', a'; \theta^-)$$

若 $$s'$$ 为终止态，则没有后续回报，$$y = r$$。

**3. 算 loss 并更新当前网络**

- 当前网络在 $$(s, a)$$ 上的预测是 $$Q(s, a; \theta)$$（注意：是**实际执行**的动作 $$a$$，不是 argmax 那个动作的 Q 值单独用来训练）。
- TD 误差为 $$y - Q(s, a; \theta)$$，loss 取均方误差（见下文 Loss 函数）。
- 对 $$\theta$$ 做梯度下降；**目标网络参数 $$\theta^-$$ 不参与这一步的梯度更新**。

**4. 存经验、采样与同步目标网络**

- 把转移 $$(s, a, r, s')$$ 存入**经验回放池**；更新时从池中随机采样 mini-batch，打破相邻样本的相关性，训练更稳定。
- 每隔 $$C$$ 步（或每回合结束），将当前网络参数拷贝到目标网络：$$\theta^- \leftarrow \theta$$。

**整体循环**（示意）：

1. 初始化当前网络、目标网络（通常 $$\theta^- \leftarrow \theta$$），清空经验回放池。
2. 重复多个回合：从初始状态出发，在未终止前循环执行上述 1～3 步，并令 $$s \leftarrow s'$$ 继续交互。
3. 达到设定步数或回合数后结束；部署时一般只用训练好的当前网络选动作。

要点：**选动作用当前网络，估未来用目标网络；标签里的 $$a$$ 是这一步真正执行的动作，loss 只拉近「预测」与「TD 目标」之间的差距。**


### Loss 函数

对一条转移 $$(s, a, r, s')$$，TD 目标与均方误差为：

$$y = r + \gamma \max_{a'} Q(s', a'; \theta^-)$$

$$L(\theta) = \bigl(y - Q(s, a; \theta)\bigr)^2$$

其中：

- **$$y$$**：TD 目标（训练标签），由即时奖励与目标网络对下一状态最优 Q 的估计组成。
- **$$Q(s, a; \theta)$$**：当前网络对「状态 $$s$$ 下动作 $$a$$」的 Q 估计。
- **$$\theta^-$$**：目标网络参数；计算 $$y$$ 时当作常数，**不对 $$\theta^-$$ 反传梯度**。
- **$$\gamma$$**：折扣因子，含义与表格型 Q-learning 相同。

实际训练时通常从经验回放池中采样一个 mini-batch，对 batch 内各样本的 $$L(\theta)$$ 取平均后再对 $$\theta$$ 做一次梯度下降。这与表格型更新

$$Q(s, a) \leftarrow Q(s, a) + \alpha \bigl[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\bigr]$$

是同一思想：括号里是 TD 误差，DQN 只是用神经网络 + 梯度下降去缩小这个误差。
