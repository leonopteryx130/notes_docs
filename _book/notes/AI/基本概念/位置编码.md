# 位置编码

### 为什么要用位置编码

Self-Attention 只看向量内容做点积，**不感知词序**。把句子打乱后，注意力结果会跟着重排；「猫追狗」和「狗追猫」若没有位置信息，几乎无法区分。

RNN / CNN 顺序是机制自带的，Self-Attention 需要**额外注入**位置。常见做法是把位置编码加到词嵌入上：

$$X = E_{\text{token}} + E_{\text{pos}}$$

> 详见 [self-Attention](../深度学习模型架构/self-Attention.md)。

### 位置编码的演进过程

1. 整型值标记位置

给第一个 token 标记 1，给第二个标记 2……以此类推。

（1）训练最长到 $$N$$ 时，更长位置从未见过，外推差。
（2）位置值无界，序列越长数字越大，加到词嵌入上后前后尺度不一致。

2. 用 [0, 1] 范围标记位置

把位置压进 [0, 1]：0 是第一个 token，1 是最后一个。长度为 $$L$$ 时第 $$i$$ 个位置（从 0 计）是 $$i / (L-1)$$。例如 3 个 token 是 $$[0,\ 0.5,\ 1]$$，4 个是 $$[0,\ 0.33,\ 0.67,\ 1]$$。

无界解决了，但相邻间距变成 $$1/(L-1)$$，随句子长短而变：短句里「相邻」差 0.5，长句里可能只有 0.11。相对位置没有统一尺度。
