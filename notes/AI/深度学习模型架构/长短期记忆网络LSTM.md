# 长短期记忆网络LSTM

### 基本思想

长短期记忆网络的设计灵感来自计算机中的逻辑门。它引入了记忆元（memory cell），简称单元（cell），用来存放序列上的长期状态。每一步都会根据当前输入，决定遗忘哪些旧信息、写入哪些新信息。

### 如何理解门

门（gate）的输出落在 $$(0,1)$$ 区间，用来**按元素缩放**另一条信息流：接近 $$1$$ 表示「几乎全放行」，接近 $$0$$ 表示「几乎全拦住」。LSTM 里的门都用 **Sigmoid** 实现，因此是可微的软开关，而不是硬截断。

三个门各管一件事：

| 门 | 符号 | 作用 |
|----|------|------|
| **遗忘门** | $$f_t$$ | 上一时刻记忆元 $$C_{t-1}$$ 里，哪些该丢掉 |
| **输入门** | $$i_t$$ | 本步候选记忆 $$\tilde{C}_t$$ 里，哪些该写进 $$C_t$$ |
| **输出门** | $$o_t$$ | 更新后的 $$C_t$$ 里，哪些对外暴露为隐藏状态 $$h_t$$ |

输入都是当前 $$x_t$$ 与上一隐藏状态 $$h_{t-1}$$（可写成拼接 $$[h_{t-1}; x_t]$$）。设输入维为 $$n$$、隐藏维（也等于记忆元维）为 $$h$$。

### 训练门和候选记忆

<div align="center">
    <img src=./长短期记忆网络LSTM1.png width=80% />
</div>

先算出三个门，以及「本步想写入」的候选记忆 $$\tilde{C}_t$$（用 **tanh**，取值在 $$(-1,1)$$）：

$$f_t = \sigma(W_{xf} x_t + W_{hf} h_{t-1} + b_f)$$

$$i_t = \sigma(W_{xi} x_t + W_{hi} h_{t-1} + b_i)$$

$$o_t = \sigma(W_{xo} x_t + W_{ho} h_{t-1} + b_o)$$

$$\tilde{C}_t = \tanh(W_{xc} x_t + W_{hc} h_{t-1} + b_c)$$

其中 $$W_{x\cdot}\in\mathbb{R}^{h\times n}$$、$$W_{h\cdot}\in\mathbb{R}^{h\times h}$$，偏置 $$b_\cdot\in\mathbb{R}^{h}$$。$$\sigma$$ 保证门值在 $$(0,1)$$；$$\tilde{C}_t$$ 则是待写入的新内容提案，尚未真正改动记忆元。

### 操作记忆元

<div align="center">
    <img src=./长短期记忆网络LSTM2.png width=80% />
</div>

记忆元的更新把「遗忘旧的」和「写入新的」合成一步（$$\odot$$ 为按元素乘）：

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

- $$f_t \odot C_{t-1}$$：按遗忘门擦除或不擦除历史
- $$i_t \odot \tilde{C}_t$$：按输入门决定候选记忆写多少进去

两条支路再相加，得到本步长期状态 $$C_t$$。梯度可沿这条几乎线性的路径跨时间步传播，从而缓解普通 RNN 的长期依赖消失问题。序列开始时常取 $$C_0 = \mathbf{0}$$、$$h_0 = \mathbf{0}$$。

### 更新隐藏层

<div align="center">
    <img src=./长短期记忆网络LSTM3.png width=80% />
</div>

隐藏状态不是直接等于 $$C_t$$，而是先把记忆元压到 $$(-1,1)$$，再经输出门过滤：

$$h_t = o_t \odot \tanh(C_t)$$

$$h_t$$ 既作为本步对外输出（再接到下游分类头等），也作为下一时刻的循环输入。直觉上：$$C_t$$ 存长期内容，$$o_t$$ 决定「此刻对外说多少」；需要保密或尚未相关的信息可以留在 $$C$$ 里，不必出现在 $$h$$ 中。
