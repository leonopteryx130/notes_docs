数据增强

数据增强

什么是数据增强

数据增强（Data Augmentation）是在不增加新标注样本的前提下，对已有训练数据做一系列保持语义/标签不变（或可推导）的变换，从而得到更多有效训练样本。

常见做法是在训练时对每个样本随机施加变换（如图像翻转、裁剪，文本同义词替换等），让模型看到同一数据的多种「变体」，而不是只记住原始样本本身。

为什么要做数据增强

深度学习模型参数量大，容易过拟合——尤其在标注数据少、采集成本高时。数据增强的核心动机是：用有限数据逼近更丰富的真实分布。

主要作用：

  • 扩充有效样本量：同一张图、同一句话经变换后可产生多种输入，降低对单一样本的记忆。
  • 提升泛化与鲁棒性：迫使模型关注不变的语义特征（物体类别、句子含义），而不是依赖特定角度、光照、用词等表面线索。
  • 缓解类别不平衡 / 稀缺场景：对少数类或难例多做增强，间接提高其在训练中的出现频率。
  • 成本低：相比重新采集和标注，增强几乎是「白嫖」数据量的手段。

注意：增强必须不破坏标签语义。例如分类任务里随机水平翻转通常安全，但 OCR、检测框方向敏感的任务则需谨慎或同步变换标注。

计算机视觉（CV）领域

以下以这张小猫照片为基图，说明常见 CV 增强手段（训练时通常对同一张图随机组合多种变换）：

1. 几何与外观变换

对像素空间做几何/色彩扰动，标签（如「猫」）通常不变。以下均由基图直接变换得到：

几何变换（移位、水平翻转、缩放裁剪、旋转）：

  • 移位（Translate）：整图平移，模拟构图偏移；边缘用填充补齐。
  • 翻转（Flip）：水平翻转后抬起的爪子换到另一侧；垂直翻转在自然场景中较少用。
  • 缩放 / 裁剪（Scale / Crop）：放大后裁局部，迫使模型不依赖固定尺度与完整构图。
  • 旋转 / 仿射：小角度旋转等，模拟握持姿态变化。

外观变换（提亮、对比度、饱和度、模糊）：

  • 滤镜与色彩抖动：改亮度、对比度、饱和度、色调，或模糊、锐化，模拟不同光照与白平衡。

这类变换实现成本低（如 torchvision.transforms、Albumentations），是 CV 增强的默认主力。

2. 加噪

在像素上叠加随机噪声，提升对传感器噪声、压缩伪影的鲁棒性。常见如椒盐噪声、高斯噪声等，详见 图像噪声：

对基图这类细腻毛发纹理，噪声会明显打乱高频细节，逼模型更依赖轮廓与语义结构。

3. 生成式 / 风格迁移变换

用 GAN、扩散模型等做更大幅度的分布外变换，例如把背景从室内粉毯换成草地，或夏季场景换成冬季——语义标签仍为「猫」，但外观域变化很大。效果强、成本高，且需保证变换不改坏标签语义（例如把猫变成狗就不算合法增强）。

自然语言处理（NLP）领域

以下以这句话为基句（标签假设为「正面评价」），说明常见 NLP 增强手段：

这部电影的剧情很精彩，演员表演也很出色。

1. EDA（Easy Data Augmentation）

包含同义词替换、随机插入、随机交换、随机删除四种基本操作，例如：

  • 同义词替换：这部电影的剧情很精彩 → 这部电影的剧情很出色
  • 随机插入：这部电影的剧情很精彩，演员表演也很出色 → 这部电影的剧情很精彩，真的演员表演也很出色
  • 随机交换：这部电影的剧情很精彩，演员表演也很出色 → 这部电影的演员很精彩，剧情表演也很出色（交换词位置；需控制幅度以免语义崩坏）
  • 随机删除：这部电影的剧情很精彩，演员表演也很出色 → 这部电影的剧情很精彩，表演也很出色

2. 回译（Back-Translation）

将文本翻译为中间语言再译回原语言，利用「语意等价、措辞不同」产生新句：

中文 → 英文：The plot of this movie is wonderful, and the actors' performances are also excellent.
英文 → 中文：这部影片的情节非常棒，演员们的表现同样很优秀。

标签仍为「正面评价」，但用词与句式已不同。

3. 同义词 / 词向量替换

借助同义词词典或 Word2Vec、Synonyms 等，替换部分关键词并保持标签不变：

这部电影的剧情很精彩，演员表演也很出色
→ 这部电影的剧情很精彩，演员表演也很优秀

4. 上下文填空（如 BERT）

随机掩盖部分词汇，让预训练模型根据上下文预测填空，生成语义更自然的句子（类似完形填空）：

这部电影的剧情很 [MASK]，演员表演也很出色
→ 这部电影的剧情很吸引人，演员表演也很出色

5. 对抗扰动

不直接改文字表面，而在词向量或隐层输出上加入微小扰动，使模型对该样本的预测更「难」、更鲁棒；表面句子可不变，但词向量空间或者语义特征空间已被轻微推动。

使用场景

  1. 迁移学习：目标域标注少时，对目标数据做增强，让预训练模型更快适应新分布，减轻过拟合。

  2. Fine-tune：小样本微调（分类、检测、情感等）时用增强扩充有效样本量，提升泛化；注意变换不能破坏标签。

  3. Agent 决策：对观测（图像、文本状态等）做扰动/变体训练，提高策略在噪声、遮挡、措辞变化下的鲁棒性。

  4. 大模型答疑：用户提问措辞多变，可用改写、回译等生成问法变体并保持答案不变，让模型学会「同问异述」也能答对。
