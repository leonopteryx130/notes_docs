全概率公式和贝叶斯公式

全概率公式和贝叶斯公式

背景知识

完备事件组

设样本空间为 Ω\OmegaΩ，事件 B1,B2,…,BnB_1, B_2, \ldots, B_nB​1​​,B​2​​,…,B​n​​ 满足：

  1. 两两互斥：i≠ji \neq ji≠j 时，Bi∩Bj=∅B_i \cap B_j = \emptysetB​i​​∩B​j​​=∅（不会同时发生）
  2. 并集覆盖全集：B1∪B2∪⋯∪Bn=ΩB_1 \cup B_2 \cup \cdots \cup B_n = \OmegaB​1​​∪B​2​​∪⋯∪B​n​​=Ω（必然发生其中一个）

则称 {B1,B2,…,Bn}\{B_1, B_2, \ldots, B_n\}{B​1​​,B​2​​,…,B​n​​} 是 Ω\OmegaΩ 的一个完备事件组（也称样本空间的一个划分）。

交事件概率 / 乘法公式

由条件概率定义 P(A∣B)=P(AB)P(B)P(A \vert B) = \dfrac{P(AB)}{P(B)}P(A∣B)=​P(B)​​P(AB)​​（要求 P(B)>0P(B) > 0P(B)>0），立刻得到乘法公式：

P(AB)=P(B)⋅P(A∣B)=P(A)⋅P(B∣A) P(AB) = P(B) \cdot P(A \vert B) = P(A) \cdot P(B \vert A) P(AB)=P(B)⋅P(A∣B)=P(A)⋅P(B∣A)

其中 ABABAB 表示交事件 A∩BA \cap BA∩B。直观含义：两件事同时发生的概率 = 一件事先发生的概率 × 在它发生的前提下另一件事发生的条件概率。

全概率公式

如上图：样本空间被完备事件组 B1,B2,…,BnB_1, B_2, \ldots, B_nB​1​​,B​2​​,…,B​n​​ 划成互不重叠的几块，事件 AAA（灰色区域）被这些边界切成若干小块 AB1,AB2,…AB_1, AB_2, \ldotsAB​1​​,AB​2​​,…。于是：

A=AB1∪AB2∪⋯∪ABn A = AB_1 \cup AB_2 \cup \cdots \cup AB_n A=AB​1​​∪AB​2​​∪⋯∪AB​n​​

且各 ABiAB_iAB​i​​ 两两互斥，所以：

P(A)=∑i=1nP(ABi)=∑i=1nP(Bi)P(A∣Bi) P(A) = \sum_{i=1}^{n} P(AB_i) = \sum_{i=1}^{n} P(B_i)\, P(A \vert B_i) P(A)=∑​i=1​n​​P(AB​i​​)=∑​i=1​n​​P(B​i​​)P(A∣B​i​​)

这就是全概率公式：先按「原因 / 场景」拆开，再把各场景下 AAA 发生的概率加总。

举个例子

假设你要去学校，有 3 种交通工具（完备事件组）：

事件 含义 先验概率 P(Bi)P(B_i)P(B​i​​)
B1B_1B​1​​ 坐公交车 0.50.50.5
B2B_2B​2​​ 骑自行车 0.30.30.3
B3B_3B​3​​ 走路 0.20.20.2

设事件 AAA 为「上学迟到」，各交通方式下的迟到条件概率为：

P(A∣B1)=0.1,P(A∣B2)=0.2,P(A∣B3)=0.4 P(A \vert B_1) = 0.1,\quad P(A \vert B_2) = 0.2,\quad P(A \vert B_3) = 0.4 P(A∣B​1​​)=0.1,P(A∣B​2​​)=0.2,P(A∣B​3​​)=0.4

由乘法公式，例如「坐公交且迟到」的概率：

P(AB1)=P(B1)⋅P(A∣B1)=0.5×0.1=0.05 P(AB_1) = P(B_1) \cdot P(A \vert B_1) = 0.5 \times 0.1 = 0.05 P(AB​1​​)=P(B​1​​)⋅P(A∣B​1​​)=0.5×0.1=0.05

同理可得 P(AB2)=0.06P(AB_2) = 0.06P(AB​2​​)=0.06，P(AB3)=0.08P(AB_3) = 0.08P(AB​3​​)=0.08。总迟到概率就是三种情境下迟到概率之和：

P(A)=P(AB1)+P(AB2)+P(AB3)=0.05+0.06+0.08=0.19 \begin{aligned} P(A) &= P(AB_1) + P(AB_2) + P(AB_3) \\ &= 0.05 + 0.06 + 0.08 = 0.19 \end{aligned} ​P(A)​​​​=P(AB​1​​)+P(AB​2​​)+P(AB​3​​)​=0.05+0.06+0.08=0.19​​

或直接套全概率公式：

P(A)=0.5×0.1+0.3×0.2+0.2×0.4=0.19 P(A) = 0.5 \times 0.1 + 0.3 \times 0.2 + 0.2 \times 0.4 = 0.19 P(A)=0.5×0.1+0.3×0.2+0.2×0.4=0.19

贝叶斯公式

全概率是「由因推果」：已知各原因的概率，求结果 AAA 的总概率。贝叶斯公式则是「由果推因」：已经观察到 AAA 发生了，反推它更可能来自哪个原因 BiB_iB​i​​。

由条件概率与乘法公式：

P(Bi∣A)=P(ABi)P(A)=P(Bi)P(A∣Bi)P(A) P(B_i \vert A) = \frac{P(AB_i)}{P(A)} = \frac{P(B_i)\, P(A \vert B_i)}{P(A)} P(B​i​​∣A)=​P(A)​​P(AB​i​​)​​=​P(A)​​P(B​i​​)P(A∣B​i​​)​​

分母用全概率公式展开，得到贝叶斯公式：

P(Bi∣A)=P(Bi)P(A∣Bi)∑j=1nP(Bj)P(A∣Bj) P(B_i \vert A) = \frac{P(B_i)\, P(A \vert B_i)}{\displaystyle\sum_{j=1}^{n} P(B_j)\, P(A \vert B_j)} P(B​i​​∣A)=​​j=1​∑​n​​P(B​j​​)P(A∣B​j​​)​​P(B​i​​)P(A∣B​i​​)​​

常用术语：

  • P(Bi)P(B_i)P(B​i​​)：先验概率（先验，prior）——还没看到结果前，对原因的信念
  • P(A∣Bi)P(A \vert B_i)P(A∣B​i​​)：似然（likelihood）——该原因下出现观测 AAA 的可能性
  • P(Bi∣A)P(B_i \vert A)P(B​i​​∣A)：后验概率（后验，posterior）——看到 AAA 之后，对原因的更新信念

承接上例

若已知你迟到了（AAA 发生），问「最可能是坐公交来的」的概率：

P(B1∣A)=P(AB1)P(A)=0.050.19≈0.263 P(B_1 \vert A) = \frac{P(AB_1)}{P(A)} = \frac{0.05}{0.19} \approx 0.263 P(B​1​​∣A)=​P(A)​​P(AB​1​​)​​=​0.19​​0.05​​≈0.263

同理：

P(B2∣A)=0.060.19≈0.316,P(B3∣A)=0.080.19≈0.421 P(B_2 \vert A) = \frac{0.06}{0.19} \approx 0.316,\qquad P(B_3 \vert A) = \frac{0.08}{0.19} \approx 0.421 P(B​2​​∣A)=​0.19​​0.06​​≈0.316,P(B​3​​∣A)=​0.19​​0.08​​≈0.421

尽管走路的先验最小（0.20.20.2），但走路迟到率最高，所以「已经迟到」时，后验上最可疑的反而是走路。先验 0.5/0.3/0.20.5 / 0.3 / 0.20.5/0.3/0.2 被观测更新成约 0.26/0.32/0.420.26 / 0.32 / 0.420.26/0.32/0.42。

二者关系小结

全概率公式 贝叶斯公式
方向 由因求果 由果求因
问的是 P(A)P(A)P(A) P(Bi∣A)P(B_i \vert A)P(B​i​​∣A)
依赖 完备事件组 + 乘法公式 全概率作分母 + 乘法公式
一句话 把各场景下的概率加起来 用观测把先验更新成后验
