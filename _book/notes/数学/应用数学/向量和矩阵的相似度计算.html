向量和矩阵的相似度计算

向量和矩阵的相似度计算

深度学习里（尤其是 Attention）常用点积衡量两个向量的相似度：方向越接近、模长越大，点积越大。

a⋅b=a⊤b=∑i=1daibi \mathbf{a} \cdot \mathbf{b} = \mathbf{a}^\top \mathbf{b} = \sum_{i=1}^{d} a_i b_i a⋅b=a​⊤​​b=∑​i=1​d​​a​i​​b​i​​

几何上：a⋅b=∥a∥∥b∥cosθ\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\|\,\|\mathbf{b}\|\,\cos\thetaa⋅b=∥a∥∥b∥cosθ。夹角越小越相似；若向量已归一化（单位向量），点积就等于余弦相似度。

求某两个向量的相似度

直接做点积：

s=q⊤k∈R s = \mathbf{q}^\top \mathbf{k} \in \mathbb{R} s=q​⊤​​k∈R

例如 q,k∈Rd\mathbf{q}, \mathbf{k} \in \mathbb{R}^{d}q,k∈R​d​​，结果是一个标量分数。

批量求某个向量和某一组 N 个向量的相似度

把 N 个 Key 排成矩阵 K∈RN×dK \in \mathbb{R}^{N \times d}K∈R​N×d​​（每行一个向量），Query 为行向量 q∈R1×d\mathbf{q} \in \mathbb{R}^{1 \times d}q∈R​1×d​​：

s=qK⊤∈R1×N \mathbf{s} = \mathbf{q}\, K^\top \in \mathbb{R}^{1 \times N} s=qK​⊤​​∈R​1×N​​

一次矩阵乘法得到 N 个相似度分数，对应「一个 Query 对一组 Key」——Attention 里最常见的打分形式。

若约定 Key 按列存放 K∈Rd×NK \in \mathbb{R}^{d \times N}K∈R​d×N​​，则写成 s=qK\mathbf{s} = \mathbf{q}\, Ks=qK，本质相同。

批量求某一组 M 个向量和某一组 N 个向量的相似度

Query 矩阵 Q∈RM×dQ \in \mathbb{R}^{M \times d}Q∈R​M×d​​，Key 矩阵 K∈RN×dK \in \mathbb{R}^{N \times d}K∈R​N×d​​：

S=QK⊤∈RM×N S = Q\, K^\top \in \mathbb{R}^{M \times N} S=QK​⊤​​∈R​M×N​​

SijS_{ij}S​ij​​ 就是第 iii 个 Query 与第 jjj 个 Key 的点积。Transformer 里一批 Query 对全部 Key 的打分就是这一步。

求某一组 N 个向量中，每个向量之间的相似度

同一组向量既当 Query 又当 Key（Self-Attention）：

S=XX⊤∈RN×N S = X\, X^\top \in \mathbb{R}^{N \times N} S=XX​⊤​​∈R​N×N​​

其中 X∈RN×dX \in \mathbb{R}^{N \times d}X∈R​N×d​​。SSS 是对称矩阵，对角线是各向量的模长平方 ∥xi∥2\|x_i\|^2∥x​i​​∥​2​​，非对角元是两两相似度。

缩放点积（Scaled Dot-Product）

维度 ddd 很大时，点积的方差大致随 ddd 增长：若各分量独立、均值为 0、方差为 1，则

Var(q⊤k)=d \mathrm{Var}(\mathbf{q}^\top \mathbf{k}) = d Var(q​⊤​​k)=d

分数绝对值容易偏大，Softmax 会变得极尖锐（接近 one-hot），梯度变小、训练不稳定。做法是除以维度的平方根：

Attention(Q,K,V)=softmax(QK⊤d)V \mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{Q K^\top}{\sqrt{d}}\right) V Attention(Q,K,V)=softmax(​√​d​​​​​QK​⊤​​​​)V

d\sqrt{d}√​d​​​ 把点积的标准差压回约 1，Softmax 输入更温和。这就是 Transformer 里的 Scaled Dot-Product Attention。
