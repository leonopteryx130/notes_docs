Q-learning

Q-learning

Q值和Q表

Q 值（动作价值）表示：在状态 sss 下执行动作 aaa，之后按策略继续交互，能获得的期望折扣回报：

Q(s,a)=E[Gt∣St=s,At=a]Q(s, a) = \mathbb{E}[G_t \mid S_t = s,\, A_t = a]Q(s,a)=E[G​t​​∣S​t​​=s,A​t​​=a]

其中 GtG_tG​t​​ 是回报（见马尔可夫链及其回报）。与贝尔曼方程里只依赖状态的 v(s)v(s)v(s) 不同，Q 值把「当前要执行的动作」也写进了条件里。

Q 表是把所有 (状态, 动作) 对的 Q 值列成的一张表；当状态和动作有限时，可用二维表格存储。Q 表不是环境事先给定的，而是训练出来的：一开始表中数值通常是任意的（例如全为 0），智能体并不知道各状态–动作的好坏；在与环境反复交互的过程中，根据奖励反馈不断修正，Q 值才逐渐收敛到有意义的估计。

例如，某环境有 3 个状态 s1,s2,s3s_1, s_2, s_3s​1​​,s​2​​,s​3​​，每个状态可执行两个动作：左 (L)、右 (R)。训练前 Q 表可能全是 0；训练后可能变成如下（数值仅为示意）：

L R
s1s_1s​1​​ 0.2 0.8
s2s_2s​2​​ 1.0 0.3
s3s_3s​3​​ 0.0 0.0

表中每个格子就是一个 Q 值：Q(s1,L)=0.2Q(s_1, L)=0.2Q(s​1​​,L)=0.2 表示在 s1s_1s​1​​ 执行 L 的期望回报为 0.2，Q(s1,R)=0.8Q(s_1, R)=0.8Q(s​1​​,R)=0.8 表示在 s1s_1s​1​​ 执行 R 的期望回报为 0.8；s3s_3s​3​​ 两个动作均为 0，可理解为终止态附近不再有后续回报。

ε-贪心

Q-learning 需要智能体在环境中试探不同动作，才能收集奖励并更新 Q 表。若每步都只选当前 Q 值最大的动作（纯贪心），容易过早卡在次优路径上，且部分状态–动作可能永远得不到尝试。ε-贪心（ε-greedy） 在利用（exploitation）已知好动作与探索（exploration）未知动作之间折中。

规则：在状态 sss 下选动作时，以概率 ε\varepsilonε 从合法动作集合 A(s)\mathcal{A}(s)A(s) 中均匀随机选一个；以概率 1−ε1 - \varepsilon1−ε 选 Q 值最大的动作：

a={Uniform(A(s)),with probability εargmaxa∈A(s)Q(s,a),with probability 1−εa = \begin{cases} \text{Uniform}\bigl(\mathcal{A}(s)\bigr), & \text{with probability } \varepsilon \\ \arg\max_{a \in \mathcal{A}(s)} Q(s, a), & \text{with probability } 1 - \varepsilon \end{cases}a={​Uniform(A(s)),​argmax​a∈A(s)​​Q(s,a),​​​with probability ε​with probability 1−ε​​

其中 ε∈[0,1]\varepsilon \in [0, 1]ε∈[0,1] 为探索率。

ε\varepsilonε 行为
000 纯贪心，只利用、不探索
111 纯随机，只探索、不利用
较小正值（如 0.1∼0.20.1 \sim 0.20.1∼0.2） 多数时候走当前最优，偶尔随机试探

训练初期 Q 表不准，需要较大探索；后期可逐渐衰减 ε\varepsilonε（如从 0.2 降到 0.05），让策略更稳定地利用已学到的 Q 值。

与 Q-learning 的关系：ε-贪心只负责选动作；无论动作是贪心还是随机选出的，只要与环境交互得到 (s,a,r,s′)(s, a, r, s')(s,a,r,s​′​​)，都按同一套 Q-learning 公式更新 Q 表。下文迷宫例子取 ε=0.2\varepsilon = 0.2ε=0.2，即约 80% 步数朝 Q 最大方向走、20% 随机拐弯，因而有机会发现宝藏路径，而不只会重复已走过的陷阱路线。

计算公式和迭代过程

Q-learning 更新规则：每步与环境交互后，用即时奖励和下一状态 Q 值的最大值来修正当前 Q 估计：

Q(s,a)←Q(s,a)+α[r+γmaxa′Q(s′,a′)−Q(s,a)]Q(s, a) \leftarrow Q(s, a) + \alpha \bigl[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\bigr]Q(s,a)←Q(s,a)+α[r+γmax​a​′​​​​Q(s​′​​,a​′​​)−Q(s,a)]

其中：

  • Q(s,a)Q(s, a)Q(s,a)：在状态 sss 下采取动作 aaa 的 Q 值。
  • α\alphaα：学习率，控制新估计值与旧估计值之间的权重。
  • rrr：在执行动作 aaa 后获得的即时奖励。
  • γ\gammaγ：折扣因子，表示未来奖励的重要性。
  • s′s's​′​​：执行动作 aaa 后观察到的新状态。
  • a′a'a​′​​：在新状态 s′s's​′​​ 下考虑的下一个动作（更新时对 maxa′\max_{a'}max​a​′​​​​ 遍历所有可选动作）。

maxa′Q(s′,a′)\max_{a'} Q(s', a')max​a​′​​​​Q(s​′​​,a​′​​) 怎么理解：更新时已经站在下一格 s′s's​′​​ 上了，但还没选下一步往哪走。公式在 s′s's​′​​ 的所有合法动作里挑 Q 值最大的那个，当作「从这里继续走，未来大概能有多好」的估计。

迭代过程（示意）：

  1. 初始化 Q 表（例如全部置 0）。
  2. 重复多个回合（episode）：
    • 从初始状态出发；
    • 在未到达终止状态前循环：按策略（如 ε-贪心）在状态 sss 下选动作 aaa，与环境交互得到奖励 rrr 和新状态 s′s's​′​​；用上式更新 Q(s,a)Q(s, a)Q(s,a)；令 s←s′s \leftarrow s's←s​′​​。
  3. 当 Q 表收敛或达到足够回合数后结束训练。
